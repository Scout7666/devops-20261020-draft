# E6 B：DRAFT 自动构建与验证教学 MVP

## 目标与流程

将 E5 手工操作中的构建与验证步骤自动执行：检查候选、固定初始样例的基础镜像、实际构建并确认缺失 make、应用候选再构建、按镜像 ID 运行程序并检查输出，最后保存 JSON 与完整日志。

模型候选来自 E5 手工取得的 DeepSeek 回复。本实现是候选回放，不调用模型，不自动生成新 Dockerfile，也不实现原论文全部生成策略。

## 学生交付

1. 可执行的自动构建与验证命令及实现代码。
2. 候选来源与模型使用方式说明，区分人工候选和自动生成。
3. 初始/修复 Dockerfile、两轮构建日志、源码哈希、镜像元数据、运行输出和结果报告。
4. 单元测试与修复过程说明：从实际错误到安装依赖再到构建/运行验证。

成功标准须同时满足构建成功、运行退出码 0、预期输出匹配。网络错误不计为缺失依赖复现。原始 Dockerfile.reference 被排除出构建上下文。
